# LOG ANALYZER

A Python tool that scans a log file for any suspicious keywords.

## HOW TO RUN
```bash
python log_analyzer.py
```

## FEATURES
- Keyword Detection :
    - ERROR
    - FAILED
    - INVALID
    - LOCKED
    - UNAUTHROIZED
    - ANONYMOUS
    - etc..
- Will be improving as I get a better understanding of concepts related to Security Analyst
